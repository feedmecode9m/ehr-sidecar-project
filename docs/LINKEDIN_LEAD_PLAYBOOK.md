### Post 2 — Security angle (gets CTO shares)

```
The wrong way to add AI to clinical notes:

❌ POST full note text from the browser to OpenAI

The pattern I'd ship to production:

✅ Client sends noteId
✅ Server fetches + summarizes
✅ Client gets summary fields only

Built this in a Next.js demo (mock FHIR, synthetic patients).

Recruiters ask "do you know HIPAA?" — I show architecture.

Link in comments 👇
```
